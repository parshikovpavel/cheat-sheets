# API

- `write_post` - сюда подставляем картинку
- `upload_image(image)` - загрузка картинки
- `get_feed(user_id, offset)` - получить ленту
- `subscription(user_id, action)` - подписать/отписать







# Асинхронные взаимодействия

- при добавлении поста post_service ---(async)--> feed_service, для получения подписок feed----(sync)---> relation_service 
- relation_service -> feed_service - при подписке/отписке

# Корнер-кейс

## Удаление картинок, которые не попали в пост

Если пользователь загрузил картинку, но потом в итоге так и не добавил ее в пост - можем добавить фичу:

- предварительно сохраняем картинку с TTL в image service
- после загрузки поста с картинкой сообщаем post service -> image service, что картинку нужно хранить постоянно
- если сообщения не пришло - картинка удаляется

## Сокращение размера хранимых лент

- экспайрим ленты пользователей, которые редко заходят
- для редких пользователей генерируем ленты на лету
- считаем заранее насколько пользователь должен быть редким, чтобы это не вылилось в большую нагрузку на post_service
